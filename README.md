## 🔨 What I'm building

**[Appelo](https://github.com/JAANINEACHRAF)** · agentic RAG that drafts answers to French public tenders

Hybrid retrieval, vector plus knowledge graph. A/B on identical corpus and embeddings: **+15 pts fact recall** on hard questions. Evaluated on 250 hand-annotated Q/A with a validation set the iteration loop never sees. **RAGAS faithfulness 0.92**, p50 latency **5.8 s**.

My favourite bug so far: the ingestion layer was silently deduplicating documents and dropping their text chunks. Fact recall went 0.26 → 0.75 once traced and patched.

<sub>`LightRAG` `LangGraph` `RAGAS` `MinerU` `FastAPI` `OpenRouter` `Docker`</sub>
